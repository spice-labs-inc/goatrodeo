# Sources — `private-keys/`

Provenance ledger for private-key fixtures — unencrypted (for derive-
public-key path coverage) and encrypted (envelope-only path coverage).

See `../README.md` for corpus-wide policies.

## Hard policy

Every unencrypted private key committed here MUST begin with this
banner (inside the PEM file, as a `#`-prefixed comment line above the
`-----BEGIN ...-----` marker where the format allows, or in a sibling
`README` line if the format does not):

```
# GOAT RODEO TEST KEY - NOT A SECRET - DO NOT USE ANYWHERE ELSE
```

These keys are test fixtures only. They are NOT suitable for any
production use. They will appear in public Git history forever — any
subsequent use would constitute credential reuse.

If project policy forbids committing any private-key material even
for tests, run `generate.sh` at CI time instead of committing keys.
