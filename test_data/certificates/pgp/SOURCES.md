## Category floor

Phase 0 coverage guidance: 15 PGP keys (v4 and v6).

## Private-key discipline

Generators that produce PGP secret keys as byproducts must `rm` those
keys before exit. Never commit a PGP `PRIVATE KEY BLOCK` of any form.
