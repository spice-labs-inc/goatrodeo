## Category floor

Phase 0 coverage guidance: 8 Java keystores, 6 PKCS#12 files.

## Password-handling note

The Certificates strategy tries `null` password only. Fixtures whose
underlying format insists on a password for read access must be flagged
in their sidecar with `Certificates:KeystoreEncrypted = "true"` and
`purls.mustContain = []`.
