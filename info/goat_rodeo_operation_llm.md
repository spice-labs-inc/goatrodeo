# How Goat Rodeo Works (LLM)

> **Navigation:** [Docs](README.md) | [API](goat_rodeo_api.md) | [Architecture](architecture.md)

## Overview
Goat Rodeo builds Artifact Dependency Graphs (ADGs) from files. Pipeline: File Discovery → Strategy Determination → ADG Building.

## Tags
- **Survey Tag** (`--tag`): single run anchor.
- **Sub-Tag** (`--package-tags`): per-package tag created by strategies. Keys: `tag`, `version`, `date`. JSON marker `"package_tag": true`.
- **Short names** (`--package-tags-short-name`): uses `artifactId` instead of `groupId:artifactId` for Maven.

## CLI Flags (relevant to phases 0-3)
- `-b, --build`, `-o, --out`, `-t, --threads`, `--maxrecords`, `--block`, `--tempdir`
- `--tag`, `--tag-version`, `--tag-date`
- `--package-tags`, `--package-tags-short-name`
- `--ingested`, `--ignore`, `--file-list`, `--exclude-pattern`

## Operation Phases
1. **File Discovery** — recursive walk, ignore `.`-prefixed. Assign MIME via Tika.
2. **Strategy Determination** — ordered vector of processors. `GenericFile` always last.
   - `MavenToProcess` groups `pom`+`jar`+`sources`+`javadocs`.
   - `Certificates` produces flat aggregated Item per keystore.
3. **ADG Building** — gitoid per artifact. Block list pruning. Container recursion (tar→zip→jar→ISO etc.). `MemStorage` node-level locking + immutable read.

## Identity Resolution (Phase 1 — Maven)
`MavenState.resolveGAV` uses a strict 5-layer chain. First complete `(groupId, artifactId, version)` wins.

| Layer | Source | Notes |
|-------|--------|-------|
| 1 | Embedded `pom.properties` | Matched to filename to avoid fat-JAR cross-talk |
| 2 | External sibling `.pom` | |
| 3 | Embedded `pom.xml` | |
| 4 | MANIFEST.MF | `Bundle-SymbolicName` / `Implementation-Title` → artifactId; `Bundle-Version` / `Implementation-Version` → version; `bundle-name` and `specification-version` as further fallbacks |
| 5 | Filename | `groupId.artifactId-version.jar` or `artifactId-version.jar` (Scala suffix guard: numeric dot-suffix stays in artifactId) |

Metadata keys: `("tag","package")`, `("tag","package tag group id")`, `("tag","repo URL")`, `("maven","Timestamp")`.

## POM Parsing (Phase 2)
`PomParser` (hardened, no `scala.xml.XML`) extracts:
- GAV with parent fallback for missing child fields.
- Three dep sets: normal, `dependencyManagement`, licenses.
- Property interpolation (`${key}`) with 10-level depth cap and cycle detection.
- Properties split into `buildProperties`, `normalizeProperties`, `allProperties`.

## Dependency Metadata (Phase 3)
- Stored as JSON under `adHoc("maven")("DEPENDENCIES")` and `adHoc("maven")("RuntimeDependencies")`.
- No new edge types.
- Default scope = `compile` when omitted.
- `parseDependencies` skips children under `<dependencyManagement>`.
- pURL reconstructible from metadata fields.

## Certificates Strategy Key Behaviors
- **Keystore = single flat Item** with aggregated pURLs/metadata, not one Item per entry.
- **Encrypted material is opaque** — envelope metadata only, no decryption, no password guessing.
- **Private key filtering** (`Certificates.filterLeaks`) drops private-key-containing entries silently (Option, not exception).

## MemStorage
Low-lock immutable map. Node-level atomic updates. Size scales with `--maxrecords`.

## Threads & Memory
- Default threads = 4.
- Use RAM disk for `--tempdir` (25G+) to avoid NVMe/SSD/HDD writes.
- Memory pressure rises with threads + in-memory `ArtifactWrapper` count.
